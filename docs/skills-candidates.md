# Skill Candidates

Track project capabilities that may justify a local or vendor skill after the
corresponding workflow or technology exists.

| Candidate | Trigger For Adoption | Current Decision |
| --- | --- | --- |
| Linear workflow | Linear becomes the durable issue/status source of truth | Defer; no repository workflow currently depends on Linear |
| Business API development | A business API app and its architecture are accepted | Defer; do not copy Triad FastAPI conventions into the IDP |
| Accessibility vendor skill | Repeated audits exceed the guidance already in app rules and preflight | Evaluate separately before installation |
| React performance skill | Measured or recurring React performance review needs emerge | Evaluate separately before installation |
| React effect guidance | Repeated reviews show avoidable effects or derived-state synchronization bugs | Evaluate separately before installation |
| Tailwind design-system skill | SAC Nexus introduces a formal cross-module token and component-system program | Defer; current Tailwind and shadcn guidance is sufficient |
| UX copy skill | Product establishes a governed Brazilian Portuguese content workflow | Evaluate separately before installation |

Downloaded skills must stay upstream-owned. Encode SAC Nexus policy in
`sac-nexus-*` wrapper skills.
