# Web Testing

This document explains the current test setup for `apps/web`.

## Test Structure

Tests are centralized under `apps/web/tests`.

Current structure:

```txt
apps/web/tests/
  e2e/
    app.spec.ts
  msw/
    server.ts
  unit/
    modules/
      shared/
        ui/
          button.test.tsx
  setup.ts
```

## Unit And Component Tests

Unit and component tests use:

- Vitest as the test runner.
- React Testing Library for React rendering and DOM assertions.
- `@testing-library/jest-dom` for custom DOM matchers.
- jsdom as the browser-like environment.

Vitest only picks up tests under `tests/unit/**/*.{test,spec}.{ts,tsx}`.

Run unit/component tests with:

```bash
pnpm --filter web test
```

## E2E Tests

E2E tests use Playwright.

Playwright tests live under `tests/e2e` and use the dev server configured in `playwright.config.ts`.

Run e2e tests with:

```bash
pnpm --filter web test:e2e
```

## Guided Journey Recordings

Stakeholder-facing journey videos are generated by scripts under
`apps/web/scripts/journey-recordings`. They use Playwright as a browser driver
but are not E2E tests and are not part of the regression suite.

Generated media belongs under `apps/web/artifacts/journey-recordings` and is
ignored by Git. See
[`journey-recordings.md`](journey-recordings.md) for recording commands,
editorial defaults, privacy constraints, and output details.

## API Mocks

MSW is configured for unit/component tests.

The test server lives in `tests/msw/server.ts` and is started from `tests/setup.ts`.

MSW currently starts with no handlers. Add handlers per test or extract shared handlers as the API surface becomes real.

## Test Placement

Use the centralized `tests` directory instead of colocating test files inside `src`.

Keep test paths mirroring the source module they cover when useful.

Example:

```txt
src/modules/shared/components/ui/button.tsx
tests/unit/modules/shared/components/ui/button.test.tsx
```

## Verification Commands

Useful commands:

- `pnpm --filter web test`
- `pnpm --filter web test:e2e`
- `pnpm --filter web typecheck`
- `pnpm --filter web build`
